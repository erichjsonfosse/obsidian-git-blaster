# Obsidian Git Blaster Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a lightweight, high-performance Obsidian plugin that automatically runs `git add`, `git commit`, and `git push` on a customizable interval or when files change (using a 5-second debounce), featuring pre-push pulling (rebase) with full merge conflict protection, smart modification-checking, and zero redundant git operations.

**Architecture:** A modular TypeScript plugin comprising:
1.  A system command runner (`GitManager`) using Node's native `child_process.exec`.
2.  A stateful coordinator (`GitScheduler`) for debounced file events and interval timers.
3.  A modern Obsidian UI containing status bar updates, ribbon trigger buttons, manual commit message prompts, and a comprehensive settings tab.

**Tech Stack:** TypeScript, Node.js (filesystem and process modules), Obsidian Developer API, Esbuild (for fast bundling).

## Global Constraints
*   **Target Environment:** Obsidian desktop client running on Linux/macOS/Windows.
*   **Git Requirements:** Relies on system-installed `git` located in the environment path.
*   **Authentication:** Must utilize active local SSH agent or credentials helper (no password/key storage in-plugin).
*   **No Redundant Commits:** Never run a commit if `git status --porcelain` is empty. Never run a push if there are no local changes and no unpushed commits.

  Create `src/git.ts`. This encapsulates all system shell operations inside the Obsidian Vault directory:
  ```typescript
  import { exec } from 'child_process';
  import * as path from 'path';

  export class GitManager {
    private vaultPath: string;

    constructor(vaultPath: string) {
      this.vaultPath = vaultPath;
    }

    private execCommand(cmd: string): Promise<string> {
      return new Promise((resolve, reject) => {
        exec(cmd, { cwd: this.vaultPath }, (error, stdout, stderr) => {
          if (error) {
            reject({ error, stdout, stderr });
          } else {
            resolve(stdout.trim());
          }
        });
      });
    }

    async hasChanges(): Promise<boolean> {
      try {
        const out = await this.execCommand('git status --porcelain');
        return out.length > 0;
      } catch (err) {
        console.error('Git Blaster: Error checking status', err);
        return false;
      }
    }

    async getModifiedFilesCount(): Promise<number> {
      try {
        const out = await this.execCommand('git status --porcelain');
        if (!out) return 0;
        return out.split('\n').filter(line => line.trim().length > 0).length;
      } catch {
        return 0;
      }
    }

    async hasUnpushedCommits(remote: string, branch: string): Promise<boolean> {
      try {
        // Run git log tracking differences between local branch and remote tracking branch
        const out = await this.execCommand(`git log ${remote}/${branch}..HEAD --oneline`);
        return out.trim().length > 0;
      } catch (err) {
        // If the tracking branch doesn't exist yet, we likely have unpushed commits
        return true;
      }
    }

    async pull(remote: string, branch: string): Promise<{ success: boolean; conflict: boolean; error?: string }> {
      try {
        await this.execCommand(`git pull --rebase ${remote} ${branch}`);
        return { success: true, conflict: false };
      } catch (err: any) {
        const stderr = err.stderr || '';
        const stdout = err.stdout || '';
        const combined = stderr + ' ' + stdout;
        
        const isConflict = combined.includes('CONFLICT') || combined.includes('Merge conflict') || combined.includes('rebase in progress');
        return {
          success: false,
          conflict: isConflict,
          error: stderr || err.error?.message || 'Unknown pull error'
        };
      }
    }

    async commit(msg: string): Promise<void> {
      await this.execCommand('git add .');
      // Escape message quotes for safety in shells
      const escapedMsg = msg.replace(/"/g, '\\"');
      await this.execCommand(`git commit -m "${escapedMsg}"`);
    }

    async push(remote: string, branch: string): Promise<{ success: boolean; offline: boolean; error?: string }> {
      try {
        await this.execCommand(`git push ${remote} ${branch}`);
        return { success: true, offline: false };
      } catch (err: any) {
        const stderr = err.stderr || '';
        const stdout = err.stdout || '';
        const combined = stderr + ' ' + stdout;

        const isOffline = combined.includes('Could not resolve host') || 
                          combined.includes('Connection timed out') || 
                          combined.includes('network is unreachable') ||
                          combined.includes('Could not read from remote repository');

        return {
          success: false,
          offline: isOffline,
          error: stderr || err.error?.message || 'Unknown push error'
        };
      }
    }

    async abortRebase(): Promise<void> {
      try {
        await this.execCommand('git rebase --abort');
      } catch (e) {
        console.warn('Git Blaster: Failed to abort rebase', e);
      }
    }
  }
  ```

  Create `src/scheduler.ts`:
  ```typescript
  import { GitManager } from './git';
  import { GitBlasterSettings } from './constants';

  export class GitScheduler {
    private gitManager: GitManager;
    private settings: GitBlasterSettings;
    private onSyncTrigger: (customMessage?: string) => Promise<void>;

    private intervalId: NodeJS.Timeout | null = null;
    private debounceId: NodeJS.Timeout | null = null;
    private onlineListener: (() => void) | null = null;

    constructor(
      gitManager: GitManager,
      settings: GitBlasterSettings,
      onSyncTrigger: (customMessage?: string) => Promise<void>
    ) {
      this.gitManager = gitManager;
      this.settings = settings;
      this.onSyncTrigger = onSyncTrigger;
    }

    updateSettings(newSettings: GitBlasterSettings) {
      this.settings = newSettings;
      this.restart();
    }

    startIntervalTimer() {
      this.stopIntervalTimer();
      if (this.settings.triggerMode === 'interval' || this.settings.triggerMode === 'both') {
        const ms = this.settings.intervalSeconds * 1000;
        this.intervalId = setInterval(() => {
          console.log('Git Blaster: Interval triggered sync');
          this.onSyncTrigger();
        }, ms);
      }
    }

    stopIntervalTimer() {
      if (this.intervalId) {
        clearInterval(this.intervalId);
        this.intervalId = null;
      }
    }

    triggerFileChangeEvent() {
      if (this.settings.triggerMode !== 'filechange' && this.settings.triggerMode !== 'both') {
        return;
      }

      if (this.debounceId) {
        clearTimeout(this.debounceId);
      }

      const ms = this.settings.debounceSeconds * 1000;
      this.debounceId = setTimeout(() => {
        console.log('Git Blaster: Debounced file change trigger');
        this.onSyncTrigger();
      }, ms);
    }

    registerOnlineListener() {
      if (this.onlineListener) return;

      this.onlineListener = () => {
        console.log('Git Blaster: Back online event detected. Running catch-up sync.');
        this.onSyncTrigger();
      };

      window.addEventListener('online', this.onlineListener);
    }

    private unregisterOnlineListener() {
      if (this.onlineListener) {
        window.removeEventListener('online', this.onlineListener);
        this.onlineListener = null;
      }
    }

    restart() {
      this.stopIntervalTimer();
      if (this.debounceId) {
        clearTimeout(this.debounceId);
        this.debounceId = null;
      }
      this.startIntervalTimer();
    }

    cleanup() {
      this.stopIntervalTimer();
      if (this.debounceId) {
        clearTimeout(this.debounceId);
      }
      this.unregisterOnlineListener();
    }
  }
  ```

- [ ] **Step 2: Implement Main Obsidian Plugin Logic**
  Replace `src/main.ts` with the fully realized plugin state coordinator and event listener hook-ins:
  ```typescript
  import { Plugin, Notice, Modal, TextComponent, ButtonComponent } from 'obsidian';
  import { GitManager } from './git';
  import { GitScheduler } from './scheduler';
  import { GitBlasterSettings, DEFAULT_SETTINGS } from './constants';
  import { GitBlasterSettingTab } from './settings';
  import * as os from 'os';

  export default class GitBlasterPlugin extends Plugin {
    settings: GitBlasterSettings;
    gitManager: GitManager;
    scheduler: GitScheduler;
    statusBarItem: HTMLElement;

    async onload() {
      console.log('Git Blaster loading...');
      await this.loadSettings();

      // Ensure vault absolute path is fetched safely
      const adapter = this.app.vault.adapter as any;
      const vaultPath = adapter.basePath;

      this.gitManager = new GitManager(vaultPath);
      this.scheduler = new GitScheduler(
        this.gitManager,
        this.settings,
        (msg) => this.runSyncPipeline(msg)
      );

      // Create discrete status bar entry
      this.statusBarItem = this.addStatusBarItem();
      this.updateStatusBar('idle');

      // Register Settings Tab
      this.addSettingTab(new GitBlasterSettingTab(this.app, this));

      // Hook up Watcher for vault changes
      this.registerEvent(
        this.app.vault.on('modify', () => this.scheduler.triggerFileChangeEvent())
      );
      this.registerEvent(
        this.app.vault.on('create', () => this.scheduler.triggerFileChangeEvent())
      );
      this.registerEvent(
        this.app.vault.on('delete', () => this.scheduler.triggerFileChangeEvent())
      );
      this.registerEvent(
        this.app.vault.on('rename', () => this.scheduler.triggerFileChangeEvent())
      );

      // Start timers and register online listener
      this.scheduler.startIntervalTimer();
      this.scheduler.registerOnlineListener();

      // Add visual ribbon icon
      this.addRibbonIcon('git-compare_arrows', 'Git Blaster: Sync now', () => {
        new Notice('Git Blaster: Manual Sync Initiated');
        this.runSyncPipeline();
      });

      // Add Command Palette manual override trigger commands
      this.addCommand({
        id: 'git-blaster-sync-now',
        name: 'Sync Vault Now (Silent)',
        callback: () => this.runSyncPipeline()
      });

      this.addCommand({
        id: 'git-blaster-custom-commit',
        name: 'Commit and Push with Custom Message...',
        callback: () => {
          new CustomCommitModal(this, (customMessage) => {
            this.runSyncPipeline(customMessage);
          }).open();
        }
      });
    }

    onunload() {
      console.log('Git Blaster unloading...');
      this.scheduler.cleanup();
      
      // Best-effort synchronous-like save on exit
      this.runFinalShutdownSync();
    }

    async loadSettings() {
      this.settings = Object.assign({}, DEFAULT_SETTINGS, await this.loadData());
    }

    async saveSettings() {
      await this.saveData(this.settings);
    }

    updateStatusBar(state: 'idle' | 'syncing' | 'synced' | 'offline' | 'conflict') {
      let icon = '💤';
      let text = 'Git: Idle';

      if (state === 'syncing') {
        icon = '🔄';
        text = 'Git: Syncing...';
      } else if (state === 'synced') {
        icon = '✅';
        text = 'Git: Synced';
      } else if (state === 'offline') {
        icon = '⚠️';
        text = 'Git: Push pending';
      } else if (state === 'conflict') {
        icon = '❌';
        text = 'Git: Conflict!';
      }

      this.statusBarItem.setText(`${icon} ${text}`);
    }

    private formatCommitMessage(template: string, filesCount: number): string {
      const now = new Date();
      const datetime = now.toISOString().replace('T', ' ').substring(0, 19);
      const hostname = os.hostname() || 'local';

      return template
        .replace('{{datetime}}', datetime)
        .replace('{{num_files}}', String(filesCount))
        .replace('{{hostname}}', hostname);
    }

    async runSyncPipeline(customMsg?: string): Promise<void> {
      this.updateStatusBar('syncing');

      try {
        const hasModified = await this.gitManager.hasChanges();
        const unpushed = await this.gitManager.hasUnpushedCommits(this.settings.remoteName, this.settings.branchName);

        // Smart Exit Guard: No local modifications and no unpushed commits
        if (!hasModified && !unpushed) {
          console.log('Git Blaster: Vault up-to-date. Sync aborted.');
          this.updateStatusBar('synced');
          return;
        }

        // 1. Pull Phase (if enabled)
        if (this.settings.pullBeforeSync) {
          console.log('Git Blaster: Pulling changes...');
          const pullResult = await this.gitManager.pull(this.settings.remoteName, this.settings.branchName);
          
          if (!pullResult.success) {
            if (pullResult.conflict) {
              new Notice('Git Blaster: Merge conflict detected! Resolving aborted. Please fix manually.');
              this.updateStatusBar('conflict');
              return;
            }
            console.warn('Git Blaster: Pull failed', pullResult.error);
          }
        }

        // 2. Commit Phase (only if there are modifications)
        if (hasModified) {
          console.log('Git Blaster: Committing changes...');
          const numFiles = await this.gitManager.getModifiedFilesCount();
          const commitMsg = customMsg || this.formatCommitMessage(this.settings.commitMessageTemplate, numFiles);
          await this.gitManager.commit(commitMsg);
        }

        // 3. Push Phase
        console.log('Git Blaster: Pushing changes...');
        const pushResult = await this.gitManager.push(this.settings.remoteName, this.settings.branchName);

        if (pushResult.success) {
          new Notice('Git Blaster: Synchronization Complete!');
          this.updateStatusBar('synced');
        } else {
          if (pushResult.offline) {
            new Notice('Git Blaster: Offline. Changes committed locally; sync pending connection.');
            this.updateStatusBar('offline');
          } else {
            new Notice(`Git Blaster Error pushing: ${pushResult.error}`);
            this.updateStatusBar('offline');
          }
        }
      } catch (err: any) {
        console.error('Git Blaster sync failed unexpectedly', err);
        new Notice('Git Blaster encountered an error. Check developer logs.');
        this.updateStatusBar('idle');
      }
    }

    private runFinalShutdownSync() {
      // In onunload(), executing async Promises might be aborted if Obsidian exits too quickly.
      // We spawn quick CLI git sync execution via direct calls.
      const adapter = this.app.vault.adapter as any;
      const vaultPath = adapter.basePath;
      const { execSync } = require('child_process');

      try {
        const checkStatus = execSync('git status --porcelain', { cwd: vaultPath }).toString();
        if (checkStatus.trim().length > 0) {
          execSync('git add .', { cwd: vaultPath });
          const nowStr = new Date().toISOString().replace('T', ' ').substring(0, 19);
          execSync(`git commit -m "Vault backup on close: ${nowStr}"`, { cwd: vaultPath });
          execSync(`git push ${this.settings.remoteName} ${this.settings.branchName}`, { cwd: vaultPath });
          console.log('Git Blaster: Sync on exit completed.');
        }
      } catch (e) {
        console.warn('Git Blaster: Exit sync timed out or failed.', e);
      }
    }
  }
  ```

  ```markdown
  # Obsidian Git Blaster

  An ultra-lightweight, extremely responsive automatic backup and sync plugin for Obsidian. It automatically commits and pushes your vault to your Git remote (e.g. GitHub/GitLab) on intervals or on file changes with safety-first conflict bailing and zero redundant Git operations.

  ## Features

  *   ⚡ **Extremely Lightweight:** Uses system Git directly via fast Node CLI shells. No bloated isomorphic-git dependencies.
  *   ⏰ **Interval Sync:** Automatically commit and push every $N$ seconds (Defaults to 300 seconds / 5 minutes).
  *   ✍️ **File Watcher Sync:** Detects modifications, creations, deletions, or renames and triggers a backup after you stop editing (Defaults to a rapid 5-second debounce delay).
  *   🔄 **Smart Git Pull/Rebase:** Keeps your git history straight and linear. Pulls remote updates before attempting any commits or pushes.
  *   🛡️ **Merge Conflict Protection:** Safely aborts and alerts you immediately if a pull conflict occurs, letting you resolve it without polluting your vaults.
  *   📉 **Zero-redundancy Syncs:** Only runs Git actions if changes are detected, or if you have pending offline local commits that need a push catch-up.
  *   🔌 **Offline-Resilient Catchups:** If you go offline, local commits are saved safely. The exact moment your network connection is restored, Git Blaster automatically catchup-pushes.
  *   🚪 **Graceful Shutdown Sync:** Automatically runs a best-effort save-and-push before Obsidian exits, making sure no thoughts are left behind.

  ## Installation

  ### Manual Installation

  1. Create a folder in your Obsidian vault: `.obsidian/plugins/obsidian-git-blaster`
  2. Copy the compiled `main.js` and `manifest.json` files from this project into that directory.
  3. Reload Obsidian, open your Settings -> Community Plugins, and toggle on **Git Blaster**.

  ## Development Setup

  Ensure you have Node.js installed on your machine.

  1. Clone this repository into your plugins directory.
  2. Run `npm install` to load dev dependencies.
  3. Build the files:
     *   `npm run dev` (Runs esbuild in continuous watch mode)
     *   `npm run build` (Creates the optimized production package `main.js`)

  ## Requirements

  *   Requires **Git** to be installed on your host system and available in your environment path.
  *   Requires your Git remote repository and local credentials (SSH keys or Git Credential Helper) to be pre-configured. Git Blaster automatically inherits your active SSH agent keys.
  ```
